Download Nova

A free study planner, AI tutor and practice quiz app for Windows. Version 1.5 "Glass", October 2026.

Nova for Windows, version 1.5

Source package (runs with Python 3). Free, no account needed.

Download Nova-app-v1.5.zip

The installer is not built yet. When it exists it will be unsigned, so Windows SmartScreen may show a warning that you can read before choosing to run it.

How to install and run

  • 1. Unzip the fileRight-click the downloaded zip and choose Extract All. You get a folder called Nova.
  • 2. Install Python 3Get it from python.org if you do not have it (3.10 or newer). Windows already includes the Microsoft Edge engine that Nova uses to show its glass window.
  • 3. Open PowerShell in the Nova folderIn File Explorer, open the Nova folder, click the address bar, type powershell, and press Enter.
  • 4. Start NovaRun the line below. Nova 1.5 needs no extra packages to run.
py main.py

Optional extras: py -m pip install Pillow lets you choose an account picture, and py -m pip install pywebview gives Nova a native window instead of an Edge app window. The older desktop version still works with py classic_main.py after py -m pip install customtkinter.

Turn on the AI tutor: open Settings, then AI connection, and paste a key. A free Gemini key from aistudio.google.com works. The key is saved only on your computer. Everything except the AI works without it.

Your data is saved on your own computer in %APPDATA%\Nova. To remove Nova completely, delete the Nova folder and that data folder.

What is inside

  • The appDashboard, Nova AI, My Subjects, Study Planner, Practice Quizzes, My Progress, Simple Terms, Settings and Account.
  • DocumentationA README with setup, the database design, and known limitations.
  • TestsAutomated tests and a manual checklist, so you can check it yourself.

Before you download

  • No keys or passwords insideThe package is checked for pasted API keys. The AI tutor needs your own key, which you add on your own computer.
  • A student projectIt is unsigned and has been tested by its developer only. The code is plain Python, so you can read it first.
  • PrivacyEverything stays on your computer. Only the messages and files you choose to send to the AI leave it, and the app asks first.
